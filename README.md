Ambiente de pré-consulta, raciocínio clínico por camadas e síntese de bem-estar com identidade visual de alto padrão (*High-Ticket*).

## 🚀 Como Executar Localmente

1. **Visualizador Web:** Dê dois cliques em `Ficha_Integrativa_por_Camadas_v3.html` para abrir em qualquer navegador (Chrome, Edge, Firefox).
2. **Exportar PDF:** Preencha os campos desejados e clique no botão **`◈ Gerar PDF Completo Preenchido`** (ou `Ctrl + P`). O motor interno converterá todos os dados digitados e opções marcadas em um relatório contínuo pronto para impressão.
